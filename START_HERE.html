현재 문항은 사람 검수 전 합성 초안입니다. 아래 결과는 미리 정한 응답·주석으로 채점기를 검증한 데모이며 실제 모델 성능이 아닙니다. 이 폴더와 사례 탐색기는 평가 정답을 포함하는 운영자용입니다.

처음 실행할 때

  1. 폴더에서 RUN_DEMO.cmd를 실행합니다.
  2. 아래 데모 보고서에서 점수와 분모를 확인합니다.
  3. 응답 검토실에서 results/demo/review_jobs.jsonl을 엽니다.
  4. 실제 평가에는 어댑터를 연결하고 README의 run → judge → score 순서를 따릅니다.

Python 3.10 이상. 데모에는 추가 설치나 API 키가 필요 없습니다.
